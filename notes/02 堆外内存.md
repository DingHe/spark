# spark.executor.memoryOverhead 参数的含义

Executor 进程除了 JVM Heap 以外，还需要额外的内存，用来存放 非堆内存开销，这个参数就是为这些 额外的开销 预留的内存大小

如果不手动配置，Spark 会按公式计算：

max(384MB, 0.10 * spark.executor.memory)

JVM 堆外（off-heap）和系统级别的开销，包括：

JVM 元数据区 (Metaspace)

线程栈 (Thread stacks)

本地库 (Native libraries)

用户代码里的 off-heap 内存（比如 sun.misc.Unsafe 分配的 direct buffer）

Python / R Worker 的内存消耗（如果是 PySpark、SparkR）

一些序列化/反序列化过程用的直接内存

最终一个 Executor 占用的容器内存大小是：

container_memory = spark.executor.memory + spark.executor.memoryOverhead


# 与spark.memory.offHeap.size参数的区别

spark.memory.offHeap.enabled=true
spark.memory.offHeap.size=1g

Spark 会启用 托管堆外内存，这部分内存由 Spark 管理（主要用于缓存、shuffle 等），类似于 JVM 堆内存（spark.executor.memory），但存放在 直接内存 (DirectBuffer)。

它是 Spark 内存池的一部分，有明确的分配/回收逻辑。



spark.executor.memoryOverhead
这是 容器级别的额外预留内存，包含所有 非堆内存开销，不只是 Spark 管理的堆外内存。

换句话说，spark.memory.offHeap.size 只是 spark.executor.memoryOverhead 的一个子集。
